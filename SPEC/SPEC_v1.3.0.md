# ChzzkVodChat v1.3 Specification

작성일 : 2026-07-07

---

## 버전 목표

v1.3은 의도치않은 버그를 제거하고 코드 최적화 및 일부 ux 개선


## 1.3 변경 사항

### API에서 받은 채팅을 메모리에 저장한 뒤, JSON 파일을 만들지 않고 바로 TXT를 생성한다.

별개로 json 저장은 설정에서 제어 가능 하도록 변경하여 txt 출력과 분리한다

 - 대화 참조

```

현재 v1.2.5 기준 코드를 보면 메모리에 저장한 뒤 TXT를 생성하고, JSON은 디스크에 잠깐 저장했다가 바로 삭제하는 방식입니다.

흐름을 순서대로 보면 다음과 같습니다.

API에서 채팅 50개씩 받아옴.
모든 채팅을 all_chats 리스트(메모리)에 저장.
수집이 끝나면 all_chats.sort() 수행.
save_chat_files(all_chats, ...) 호출.
여기서
all_chats → JSON 파일 저장
같은 all_chats → TXT 파일 저장

TXT 저장이 끝나면

json_path.unlink()

로 JSON 파일 삭제.

즉 실제 동작은

API
 ↓
메모리(all_chats)
 ↓
JSON 저장
 ↓
TXT 저장
 ↓
JSON 삭제

입니다.

그런데 JSON 저장이 사실 필요할까?

현재 구조에서는 필요 없습니다.

왜냐하면 TXT도 같은 all_chats 리스트를 그대로 사용해서 만들기 때문입니다.

현재는

all_chats
   ↓
json.dump(...)
   ↓
for chat in all_chats:
    TXT 작성

이라 JSON 파일을 다시 읽는 과정이 전혀 없습니다.

따라서 다음처럼 바꿀 수 있습니다.

API
 ↓
메모리(all_chats)
 ↓
TXT 생성
 ↓
끝

이렇게 하면

JSON 저장 I/O 제거
JSON 삭제 과정 제거
SSD 쓰기 감소
속도 약간 향상
코드도 더 단순해집니다.
개인적인 권장

이미 분석 모드도 TXT만 읽도록 변경되어 있으므로, v1.3에서는 JSON 생성 자체를 없애는 것이 가장 깔끔한 구조입니다.

즉 save_chat_files()를

메모리(all_chats)
      ↓
TXT 저장
      ↓
return txt_path

만 수행하도록 변경하면 됩니다. 이렇게 해도 현재 기능에는 영향이 없습니다.

```

이외에도 json -> txt 변경과 관련있는 함수, 변수들을 제거한다.

ex) load_chat_json(), json_path(), json_path_unlink() 등등

단 기능 구현 시 스스로 생각하여 더 효율적인 방식으로 수정할 수 있도록 한다

### 설정 파일명과 내부 configformat 값도 버전과 연동

 - 설정 파일명 양식을 다음과 같이 변경 ex) CVC_setting_v{program_version}.txt
 - ex) configformat = 1 -> Configformat = {program_version}
 - configformat 값이 같을 경우에만 덮어쓰기하고 다를경우에는 삭제하지 않는다
 - 이때 변수 이름이 Version 으로 변경하는 것이 직관적

### 설정에서 채팅 수집 모드 최대 수집 개수 변경 옵션 제거

 - 최대 30개 채팅 수집 유지
설정 변경 관련 코드나 변수 최적화

위 두 변경 사항을 참고해서 설정 파일을 개편할것

예시

```

# ==========================================
# CHZZK VOD CHAT Settings
# ==========================================

Version={program_version}

[Collect]

; 수집 파일이 저장될 폴더입니다.
; 프로그램 실행 폴더를 기준으로 생성됩니다.
OutputFolder=chat

; txt 파일만 필요하다면 0, json 파일이 추가로 필요할 경우 1로 변경하시면 됩니다.
SaveJson=0

[Analyze]

; 분석 실행 시 기본으로 사용할 키워드입니다.
; 입력 없이 Enter를 누르면 이 키워드가 사용됩니다.
DefaultKeyword=ㅋ

; 채팅 분석 모드의 키워드 수집 설정입니다.
; 하나의 채팅에서 동일 키워드를 최대 몇 번까지 카운트할지 설정합니다.
; 0으로 설정하면 제한 없이 모두 카운트합니다.
MaxKeywordRepeat=5

; TOP 구간에 포함하기 위한 최소 채팅 수를 설정합니다.
; 0으로 설정하면 방송 전체 평균 채팅 수를 자동으로 사용합니다.
TopMinimumChatCount=0

; 이동 평균 계산에 사용할 이전 구간(분)입니다.
; 값이 클수록 평균이 부드럽게 계산됩니다.
MovingAverageMinutes=15


[Display]

; 채팅 분석 기능의 각 TOP 목록에 출력할 최대 개수입니다.
TopCount=10

; 채팅 수집 확인에서 표시할 방송 제목의 최대 글자 수입니다.
; 길어질 경우 자동으로 ... 처리합니다.
PreviewTitleWidth=18

; 분석 결과 파일에 상세 로그를 포함할지 설정합니다.
; False로 설정하면 TOP 결과만 저장합니다.
SaveDetailLog=True

```

### 채팅 분석만 했을때 폴더를 새로 생성하지 않으니 폴더 생성변수 따로 만들고 수집, 분석 둘 다 생성할 수 있도록 한다

 - 현재 1.2.5 버전은 채팅 분석을 먼저 시도 할 경우 경로 폴더 생성이 안 됨 수정 필요

### txt 파일을 window 창으로 드래그 시 출력되는 경로도 양식에 추가하여 인식할 수 있도록 변경

### 분석 모드에서 분석 구간 입력시 시간 양식을 여유롭게 둘 수 있도록 한다
숫자 6개 입력시 ex) 012345 -> 01:23:45
숫자 4개 입력시 ex) 2222 -> 00:22:22

```
프로그램 실행
│
├─ 설정 파일 확인
│   ├─ if 버전 유효 설정 존재
│   │   └─ 설정 불러오기
│   └─ else
│       └─ 안내 후 기본 설정 생성
│
├─ 메인 메뉴
│   │
│   ├─ 사용자 입력 확인
│   │   │
│   │   ├─ if URL 인식 → 채팅 수집 모드
│   │   │   │
│   │   │   ├─ 수집 정보 확인
│   │   │   ├─ 채팅 수집
│   │   │   ├─ 폴더 생성
│   │   │   ├─ 결과 출력
│   │   │   └─ 메인 메뉴 복귀
│   │   │
│   │   ├─ else if TXT 인식 → 채팅 분석 모드
│   │   │   │
│   │   │   ├─ 분석 구간 입력
│   │   │   │   ├─ 시작 시간
│   │   │   │   └─ 종료 시간
│   │   │   ├─ 키워드 입력
│   │   │   ├─ 분석 정보 확인
│   │   │   ├─ 채팅 분석 실행
│   │   │   ├─ 폴더 생성
│   │   │   ├─ 결과 출력
│   │   │   └─ 메인 메뉴 복귀
│   │   │
│   │   └─ else 안내 후 메인 메뉴 복귀
│   │
│   └─ ESC 입력 → 프로그램 종료
│
└─ 프로그램 종료
```

### 각 구간별 요구 조건

프로그램 실행

- 정상 실행 되는가
- 중복 실행해도 각 window 별로 정상 동작 하는가

설정 파일

- 설정이 존재하지 않을 경우 기본 설정을 생성하는가
- 프로그램에 입력되어있는 설정 양식과 유효하지 않을 경우 안내 문구 출력을 하는가
- 설정 파일 일부 항목만 누락되어 있을 경우 정상적으로 복원하는가
- 설정 파일에 알 수 없는 항목이 있어도 정상적으로 동작하는가
- 유효하지 않은 설정을 기본 설정으로 덮어 쓰기를 할때 (y/n) 으로 사용자에게 덮어쓰기 여부를 물어보는가

메인 메뉴

- 메인 메뉴 UI를 정상 출력하는가
- 프로그램 제목 및 버전 정보가 정상적으로 표시되는가
- 입력 대기 상태가 활성화 되는가

사용자 입력 확인

- 프로그램이 요구하는 양식과 다른 입력을 할 경우 안내를 하는가
- URL과 TXT 파일명을 함께 입력할 경우 안내하는가
- 최대 입력 개수를 초과할 경우 적절히 처리하는가

URL 인식 → 채팅 수집 모드

- URL을 정상적으로 입력받는가
- 유효한 치지직 다시보기 VOD URL이 아닐경우 안내를 하는가
- 여러 개의 URL을 줄바꿈으로 입력할 경우 모두 인식하는가
- 중복된 URL을 입력할 경우 적절히 처리하는가
- 빈 입력 시 메인 메뉴로 복귀하거나 안내하는가
- VOD 정보를 정상적으로 조회하는가

수집 정보 확인

- 수집 정보 확인 화면이 정상적으로 표시되는가
- 수집 정보 확인 후 (y/n) 입력을 통해 진행 혹은 취소가 가능한가
- 방송 제목이 설정한 길이를 초과할 경우 ...으로 표시되는가

채팅 수집

- 채팅 수집이 정상적으로 시작되는가
- 진행률이 정상적으로 갱신되는가
- 현재 수집 개수가 정상적으로 표시되는가
- 총 수집 개수가 실제 채팅 수와 일치하는가
- 중복 채팅이 저장되지 않는가
- 채팅이 없는 구간도 정상적으로 처리하는가
- 첫 번째 채팅과 마지막 채팅이 누락 없이 저장되는가
- 동일한 시간의 채팅도 모두 저장되는가
- VOD의 시작부터 끝까지 정상적으로 수집되는가
- 수집 중 네트워크 오류 발생 시 적절히 처리하는가
- 수집 중 일시적인 API 오류 발생 시 복구 가능한가

폴더 생성

- 프로그램 경로에 설정한 이름의 폴더가 정상적으로 생성되는가

결과 출력

- 수집 완료 후 TXT 파일이 생성되는가
- TXT 파일명이 올바르게 생성되는가
- 동일한 파일명이 존재할 경우 적절히 처리하는가
- 닉네임이 정상적으로 저장되는가
- 프로필 정보를 읽을 수 없는 경우 Unknown으로 저장되는가
- 채팅 시간이 정상적으로 기록되는가
- 채팅 내용이 누락 없이 저장되는가
- 채팅이 시간순으로 저장되는가
- 이모지 및 한글이 정상적으로 저장되는가
- 특수문자가 포함된 채팅도 정상적으로 저장되는가
- 빈 채팅이 저장되지 않는가
- 수집 완료 메시지가 정상적으로 출력되는가
- 수집 완료 후 메인 메뉴로 정상 복귀하는가

TXT 인식 → 채팅 분석 모드

- TXT 파일 경로를 정상적으로 입력받는가
- 존재하지 않는 파일 경로를 입력할 경우 안내하는가
- TXT 파일이 아닐 경우 안내하는가
- 빈 입력 시 메인 메뉴로 복귀하거나 안내하는가
- TXT 파일을 정상적으로 읽는가
- TXT 형식이 올바르지 않을 경우 안내하는가

분석 구간 입력

- 시작 시간을 정상적으로 입력받는가
- 종료 시간을 정상적으로 입력받는가
- HH:MM:SS 형식을 정상적으로 인식하는가
- 숫자만 입력받아도 HH:MM:SS로 인식하는가
- 잘못된 시간 형식을 입력할 경우 안내하는가
- 음수 또는 범위를 벗어난 시간을 입력할 경우 안내하는가
- 시작 시간이 종료 시간보다 늦을 경우 안내하는가
- 종료 시간을 먼저 잘못 입력한 경우 다시 입력할 수 있는가
- 방송 길이를 초과하는 시간을 입력할 경우 안내하는가
- 빈 입력 시 기본값 또는 전체 구간이 정상적으로 적용되는가(설계 기준)
- 시작 시간과 종료 시간이 동일한 경우 정상적으로 처리하는가
- 분석 범위 밖의 채팅이 정상적으로 제외되는가

키워드 입력

- 키워드를 정상적으로 입력받는가
- 공백이 포함된 키워드를 정상적으로 처리하는가
- 특수문자가 포함된 키워드를 정상적으로 처리하는가
- 한글, 영어, 숫자 키워드를 정상적으로 처리하는가
- 키워드 입력 형식이 잘못된 경우 안내하는가

분석 정보 확인

- 분석 예상 시간이 정상적으로 표시되는가
- 분석 정보 확인 화면이 정상적으로 표시되는가
- 분석 정보 확인 후 (y/n) 입력을 통해 진행 혹은 취소가 가능한가

채팅 분석 실행

- 채팅 분석이 정상적으로 시작되는가
- 채팅이 올바른 분(Minute)으로 집계되는가
- 분 경계(00초) 채팅이 올바른 구간에 포함되는가
- TXT 파일 인코딩을 정상적으로 읽는가
- 방송 길이를 조회하지 못할 경우 채팅 시간을 기준으로 분석 범위를 계산하는가
- 입력한 시간 범위만 분석하는가
- 대용량 채팅 파일도 정상적으로 분석하는가

폴더 생성

- 프로그램 경로에 설정한 이름의 폴더가 정상적으로 생성되는가

결과 출력

- 하나의 채팅에서 동일 키워드가 설정 횟수까지만 카운트되는가
- 분석 결과의 총 채팅 수가 분석 범위 내 실제 채팅 수와 일치하는가
- 키워드가 여러 번 등장해도 정상적으로 합산되는가
- 채팅량 TOP이 정상적으로 계산되는가
- 최소 채팅 수를 0으로 설정한 경우 전체 평균이 적용되는가
- 최소 채팅 수를 직접 지정한 경우 해당 값이 적용되는가
- 최소 채팅 수 미만 구간이 TOP에서 제외되는가
- 이동평균 TOP이 정상적으로 계산되는가
- 이동평균 계산 시 설정한 이전 N분만 사용하는가
- 이동평균 계산 대상이 부족한 초기 구간도 정상적으로 처리하는가
- 이동평균이 0인 경우 증가율을 정상적으로 처리하는가
- 키워드 수량 TOP이 정상적으로 계산되는가
- 키워드 비율 TOP이 정상적으로 계산되는가
- 연속된 TOP 구간이 하나의 구간으로 병합되는가
- 연속되지 않은 TOP 구간은 병합되지 않는가
- 병합 후에도 TOP 개수가 설정값을 초과하지 않는가
- 병합된 구간 내부가 시간순으로 출력되는가
- 병합 기준이 모든 TOP 종류에서 동일하게 적용되는가
- 하나의 구간만 선택된 경우 병합 없이 정상 출력되는가
- 동일 채팅량일 경우 시간순으로 정렬되는가
- 동일 키워드 수일 경우 시간순으로 정렬되는가
- 동일 증가율일 경우 시간순으로 정렬되는가
- 동일 키워드 비율일 경우 키워드 수, 시간순으로 정렬되는가
- 키워드가 없는 경우에도 정상적으로 결과를 출력하는가
- TOP 대상이 없는 경우에도 정상적으로 결과를 출력하는가
- 채팅이 없는 구간을 정상적으로 처리하는가
- 상세 로그가 정상적으로 출력되는가
- 결과의 시간 정보가 실제 방송 시간과 일치하는가
- 채팅량 TOP이 채팅량 기준으로 정렬되는가
- 이동평균 TOP이 증가율 기준으로 정렬되는가
- 키워드 TOP이 키워드 개수 기준으로 정렬되는가
- 키워드 비율 TOP이 키워드 비율 기준으로 정렬되는가
- TOP 개수가 설정값만큼 출력되는가
- 분석 결과가 누락 없이 출력되는가
- 분석 시작 시간이 00:00:00이 아닌 경우에도 출력 시간이 정상적으로 보정되는가
- 병합 구간의 시작·종료 시간이 올바르게 계산되는가
- 상세 로그 저장 설정(True/False)이 정상적으로 적용되는가
- 상세 로그가 분석 범위만 출력되는가
- 상세 로그의 시간순이 올바른가
- 마지막 분석 구간이 정상적으로 생성되는가
- 분석 완료 메시지가 정상적으로 출력되는가
- 분석 완료 후 메인 메뉴로 정상 복귀하는가
- 결과 파일명이 정상적으로 생성되는가
- 기존 결과 파일이 있을 경우 정상적으로 덮어쓰는가
