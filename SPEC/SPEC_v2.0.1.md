# ChzzkVodChat v2.0.1 Specification

작성일: 2026-11-11

## 1. 목적과 적용 기준

v2.0 GUI 구현 이후 사용자가 요청한 추가·수정 사항을 정리한다. 입력 방식, 목록 조작, 결과물 가독성, 완료 작업 재실행 방지 및 실행파일 사용자 안내를 개선하는 것이 목적이다.

- 기준 문서는 [SPEC_v2.0.md](SPEC_v2.0.md)이다. 이 문서에서 변경한 항목은 v2.0보다 우선한다.
- 같은 항목에 여러 요청이 있었으면 가장 나중에 요청한 방식을 적용한다. 중간 단계의 UI를 함께 남기지 않는다.
- 별도로 변경하지 않은 수집 무결성, 분석 산식, 설정 복구, 비동기 작업 분리, TXT 호환성 및 안전한 저장 정책은 v2.0을 유지한다.
- 이 문서는 요구사항 정리다. 문서에 항목이 있다고 해서 구현 완료나 실서비스 검증 완료를 의미하지 않는다. 검증 기록은 [QA/v2_implementation.md](../QA/v2_implementation.md)에서 별도로 관리한다.
- 문서 버전 `2.0.1`만으로 실행파일 이름·창 제목·설정 스키마가 자동 변경되는 것은 아니다. 배포 버전 표기 변경은 별도 작업으로 관리한다.

## 2. 주요 변경 요약

| 항목 | 최종 요구사항 |
|---|---|
| URL 등록 | 안내 문구와 입력칸을 테두리 안에 배치하고, 등록 시 그 테두리 전체를 영상 항목으로 전환 |
| URL 플레이스홀더 | 사용하지 않음 |
| URL `[+]` 툴팁 | 제거 |
| 영상 정보 | 채널·제목·길이에 방송 날짜 추가, 게시 날짜와 구분 |
| 종료 입력 | 자동 끝 체크박스 제거, URL 정보 조회 후 영상 끝 시간을 실제 값으로 자동 입력 |
| 종료 빈칸 | 영상 끝까지 적용. 길이 없는 TXT는 채팅 데이터 끝까지 적용 |
| TXT 등록 | 단일 파일에서 복수 파일 등록·파일별 입력·개별 삭제로 변경 |
| 목록 | 항목별 테두리와 마우스 휠 스크롤 제공 |
| 옵션 스크롤 | 실제 옵션 내용의 상·하한 밖으로 이동하지 않도록 제한 |
| 옵션 버튼 | 적용 / 취소 / 기본값 복원 세 개로 통합 |
| 옵션 안내 | v1.3 설정 파일처럼 옵션별 적용 설명 제공 |
| 수집 TXT 시간 | 소수 초를 제거하고 HH:MM:SS로 표시, 선택 시 :00만 추가 |
| 분석 TXT | v1.3 결과물과 비슷한 구분선·순위·통계 배치, 방송·분석 정보 서식 통일 |
| 완료 작업 | 같은 시간·키워드의 완료 결과가 있으면 URL 작업 건너뛰기 |
| 방송 시각 | API 방송 시작 시각 사용, 종료는 시작+영상 길이의 계산값으로 표시 |
| 결과 조작 UI | 실행 버튼 옆 저장 폴더 열기만 유지 |
| 배포·문서 | 기존 아이콘의 GUI EXE, 실행파일 사용자 중심 README |

## 3. 수집·분석 탭

### 3.1 URL 입력 카드

URL 등록 전에는 목록 마지막에 다음 구조의 테두리 항목을 표시한다.

```text
┌──────────────────────────────────────────┐
│ URL 입력 후 Enter로 등록                  │
│ [                                   ][+] │
└──────────────────────────────────────────┘
```

- 안내 문구는 입력칸 위에 항상 보이는 라벨로 제공한다. 입력칸의 플레이스홀더는 제거한다.
- Enter 또는 `[+]`로 유효한 URL을 등록한다. `[+]`의 마우스 오버·포커스 툴팁은 제공하지 않는다.
- 등록하면 기존 입력 카드의 테두리 전체가 해당 영상의 항목으로 전환되고, 목록 마지막에 새 입력 카드를 만든다.
- 등록된 항목도 같은 계열의 테두리를 사용하고 항목 사이에 간격을 두어 영상별 구분을 명확히 한다.
- 잘못된 URL·중복 URL을 입력해도 기존 영상 항목과 입력값을 잃지 않는다.
- 최대 10개, 같은 VOD 중복 등록 금지, 줄바꿈 URL 붙여넣기, 개수 표시, 10개 도달 시 입력 비활성화는 유지한다.
- 항목 삭제 시 입력을 다시 활성화한다.

### 3.2 등록된 영상 정보

- 각 항목에 URL, 채널명, 방송 제목, 영상 길이와 방송 날짜를 표시한다.
- 방송 시작 날짜와 VOD 게시 날짜가 다를 수 있으므로 구분한다. 게시 날짜를 방송 시작 날짜로 단정하지 않는다.
- 영상 길이는 `HH:MM:SS`로 표시한다.
- `[-]`로 영상 항목과 개별 입력값을 함께 제거한다. 다른 영상은 영향을 받지 않는다.
- 정보 조회 실패 시 오류와 재조회 수단을 제공한다.
- 조회 중 삭제·재추가한 항목과 연속 재조회의 이전 응답을 현재 항목에 잘못 적용하지 않는다.
- URL 추가는 정보 조회까지만 수행하고, 수집·분석은 실행 버튼으로 시작한다.

### 3.3 마우스 휠과 이동 범위

- 목록의 빈 공간뿐 아니라 영상 정보·라벨·입력칸 위에서도 마우스 휠로 목록을 이동할 수 있어야 한다.
- 테두리·입력칸·버튼이 서로 겹치거나 잘리지 않도록 배치한다.
- 내용이 화면보다 짧으면 빈 영역만 보이도록 스크롤되지 않아야 한다.
- 내용 길이나 창 크기가 변경되어도 현재 내용에 맞게 이동 범위를 갱신한다.

## 4. 시작·종료·키워드 입력

### 4.1 초기값과 종료 시간 자동 입력

- 시작은 실제 값 `00:00:00`으로 초기화한다.
- 키워드는 저장된 기본 키워드를 사용하며, 별도 설정이 없으면 `ㅋ`를 사용한다. 다른 항목의 편집값을 복사하지 않는다.
- 별도의 `자동 끝` 체크박스는 제공하지 않는다.
- **URL 정보 조회가 성공하면 해당 영상의 끝 시간을 종료 입력칸에 실제 값으로 자동 입력한다.**
- 자동 입력된 종료를 사용자가 편집하지 않았다면 내부적으로 영상 끝까지 분석하는 의미를 유지한다. 자동 입력 때문에 명시적 종료로 바뀌어 마지막 채팅이 제외되어서는 안 된다.
- 재조회 시 자동 입력 상태의 종료는 새 영상 길이에 맞춰 갱신할 수 있다.
- 사용자가 직접 수정한 종료는 재조회나 다른 URL 추가로 덮어쓰지 않는다.
- 길이를 모르면 임의의 0초·마지막 채팅 시각을 영상 길이로 채우지 않는다.
- 종료를 비우면 알려진 영상 끝까지 적용한다. 길이를 모르는 TXT는 v2.0의 채팅 데이터 기준 종료 경계를 사용한다.
- 마지막 요청의 실제 값 자동 입력은 URL 정보 조회에 적용한다. TXT의 종료 입력·빈칸 처리는 TXT 메타데이터 유무에 맞춰 유지한다.

### 4.2 입력 형식과 툴팁

입력 형식 표기는 다음과 같이 통일한다.

| 입력 | 툴팁 기준 문구 |
|---|---|
| 시작 시간 | `HH:MM:SS / HHMMSS / MMSS, 빈칸=00:00:00` |
| URL 종료 시간 | `HH:MM:SS / HHMMSS / MMSS, 시작 시간보다 크게 설정, 빈칸=영상 종료 시간` |
| 길이 없는 TXT 종료 시간 | `HH:MM:SS / HHMMSS / MMSS, 시작 시간보다 크게 설정, 빈칸=채팅 데이터 끝까지` |
| 키워드 | 최대 10자, 빈칸=ㅋ, 사용 가능한 문자 안내 |

- URL 툴팁에 TXT 전용 안내가 섞이지 않도록 한다.
- 길이를 아는 TXT의 종료 안내는 영상 종료 시간을 기준으로 한다.
- `HHMMSS`는 숫자 6자리, `MMSS`는 숫자 4자리다. 기존 파서의 해석을 유지한다.
- 사용자의 종료 툴팁 요청은 “시작 시간 이상”이라는 표현을 예시로 들었지만, 같은 시작·종료는 분석 범위가 없어 오류라는 v2.0 정책은 변경하지 않는다. 툴팁도 실제 검증과 맞춘다.
- 종료 칸 아래에는 원래 영상 길이를 비교할 수 있는 안내를 유지한다. TXT 길이를 모를 때는 정확히 `빈칸=채팅 데이터 끝까지`로 표시한다.
- 시작·키워드 빈칸의 기본값 안내와 키보드 포커스 도움말은 유지한다.

## 5. 채팅 분석 탭

- 파일 선택 창에서 복수의 수집 TXT를 함께 등록할 수 있어야 한다.
- 여러 번 파일을 추가해 목록을 구성할 수 있어야 한다.
- 파일마다 테두리 항목을 제공하고 파일명, 읽기 상태, 확인 가능한 방송 정보, 시작·종료·키워드를 표시한다.
- 각 파일의 분석 입력값은 독립적으로 유지한다.
- 등록 항목에 `[-]` 등 명확한 개별 제거 수단을 제공한다. 여기서 제거는 분석 목록 등록 취소이며 원본 TXT 삭제가 아니다.
- 파일을 제거해도 다른 파일의 입력값은 유지한다. 읽기 중 제거한 파일의 늦은 응답도 무시한다.
- 새 형식과 기존 v1.3 수집 TXT를 모두 읽고 원본을 수정하지 않는다.
- 재수집 없이 준비 완료된 파일을 분석하며, 읽기 중·실패 항목을 제외하면 이를 안내한다.
- 수집·분석 탭의 출력 체크박스는 TXT 분석 실행에 영향을 주지 않는다.
- 같은 파일을 다른 옵션으로 반복 분석할 수 있다. 8절의 URL 완료 작업 건너뛰기를 이 탭에 일괄 적용하지 않는다.
- 파일 내용 재로딩은 기존 등록을 제거한 뒤 다시 추가하는 방식으로 제공할 수 있다.
- TXT 목록에도 항목 구분과 마우스 휠 이동을 제공한다.

## 6. 옵션 탭

### 6.1 버튼과 저장 동작

옵션 조작 버튼은 다음 세 개만 제공한다. 저장 위치의 `찾아보기` 등 개별 설정에 필요한 선택 수단은 유지한다.

| 버튼 | 동작 |
|---|---|
| 적용 | 공통 편집값을 검증하고 실행 설정과 다음 실행의 기본값을 함께 저장 |
| 취소 | 적용 전 편집값을 마지막 적용 상태로 되돌림 |
| 기본값 복원 | 확인 후 기본 설정을 적용·저장 |

- 별도 `기본값 저장` 버튼은 제거한다.
- 적용하지 않은 편집값으로 작업을 시작하지 않는다.
- 설정 변경은 이미 실행한 작업의 설정 복사본에 영향을 주지 않는다.
- 적용 시 영상별 시간·키워드·조회 결과를 다른 영상의 기본값으로 저장하지 않는다.
- 저장 실패를 안내하고, 적용·저장 성공으로 잘못 표시하지 않는다.

### 6.2 옵션별 설명

사용자가 제공한 `멀럭킹/CVC_setting_v1.3.txt`의 주석처럼, 각 옵션이 어떤 결과를 바꾸는지 옵션 근처에 설명한다. 파일은 로컬 참고 자료이며 배포본에 포함되어 있다고 가정하지 않는다.

| 옵션 | 설명에 포함할 내용 |
|---|---|
| 저장 위치 | 결과를 저장하는 위치, 채널별 하위 폴더, 기존 파일 새 이름 저장 |
| 새 영상 기본 키워드 | 새 URL·TXT의 초기값이며 이미 등록한 항목은 변경하지 않음, 1~10자 |
| 분석 단위 | 1~10분, VOD 0 기준 정렬, 5분 구간 예시, 부분 구간 처리 |
| TOP 개수 | 네 TOP 목록 각각의 최대 순위 수, 후보 부족 시 결과 수가 적을 수 있음 |
| 이동평균 이전 N분 | 현재 제외, 분석 단위의 배수, 유효값 예시, 평균 0의 N/A 처리 |
| 최소 채팅 수 | TOP 후보 최소 컷, 0=분석 범위의 구간당 평균, 무채팅·부분 구간 포함 |
| 키워드 반복 제한 | 메시지당 최대 반복 횟수, 0=무제한, 포함 채팅 비율과의 차이 |
| 최대 병합 구간 수 | 0=무제한, 1=병합 안 함, 분석 단위와 곱한 실제 길이 예시 |
| 상세 로그 | 전체 분석 구간의 시간순 통계 추가 여부 |
| 프리미어 시간 표시 | :00 추가만 수행, FPS·실제 프레임 변환 아님 |
| 수집 TXT 실제 시각 | 근거가 있을 때의 표시와 근거가 없을 때의 미확인 처리 |

- 설명은 화면에서 읽을 수 있게 배치하고, 필요한 경우 툴팁을 함께 제공한다.
- 옵션 설명을 추가했다는 이유로 설정 기본값이나 분석 산식을 바꾸지 않는다.

### 6.3 스크롤 경계

- 옵션과 설명이 화면보다 길면 마우스 휠로 이동한다.
- 마지막 옵션 아래의 불필요한 빈 영역까지 계속 이동할 수 없어야 한다. 위쪽 경계도 넘지 않아야 한다.
- 이동 범위는 현재 옵션 내용의 실제 높이를 기준으로 한다. 이전 레이아웃 높이나 오래된 스크롤 영역을 사용하지 않는다.
- 창 크기와 설명 줄바꿈이 바뀌면 이동 범위를 갱신하고, 내용이 화면보다 짧으면 스크롤을 원점에 제한한다.
- 적용·취소·기본값 복원 버튼은 옵션을 스크롤해도 접근할 수 있도록 배치한다.

## 7. 결과 조작 영역 단순화

- 각 실행 버튼 옆에 `저장 폴더 열기`를 둔다.
- 하단의 별도 작업 취소 버튼, 결과 경과 시간 복사, 결과 파일 열기, TXT 경로 선택·표시 컨트롤, 분석 결과 미리보기 버튼은 제거한다.
- 진행 상태, 오류 안내, 작업 로그와 진행 표시는 유지한다.
- 개별 URL·TXT 등록 취소용 `[-]`는 제거하지 않는다.
- 별도 작업 취소 버튼을 없애더라도 작업 중 창 닫기의 취소·종료 확인과 완료 파일 보존 정책은 유지한다.
- 결과 파일은 저장 폴더를 열어 확인한다. 수집·분석의 출력 체크박스는 유지한다.

## 8. 완료된 URL 작업의 중복 실행 방지

### 8.1 사용자 요구

- 이미 완료된 결과가 있는 영상은 시간이나 키워드를 바꾸지 않은 상태에서 실행을 눌러도 다시 수집·분석하지 않는다.
- 여러 영상 중 조건이 같은 완료 항목만 건너뛰고, 새 항목이나 변경된 항목은 실행한다.
- 건너뛴 이유를 해당 항목이나 실행 안내에 표시한다.
- 실패·취소·불완전 수집을 정상 완료로 기록하거나 재실행 금지 대상으로 삼지 않는다.
- 실행 중 사용자가 입력을 편집해도 완료 판정은 실제로 실행한 입력 복사본을 기준으로 한다.

### 8.2 현재 구현을 기준으로 정리한 세부 정책

- 표시 문자열만 비교하지 않고 해석된 시작·종료와 적용 키워드를 기준으로 판정한다. 같은 시간을 다른 입력 형식으로 쓴 것은 실제 시간 변경으로 보지 않는다.
- 영상 끝까지 자동 분석과 사용자가 직접 지정한 종료는 끝점 포함 정책이 다르므로 구분한다.
- 완료 기록과 이번에 선택한 결과 파일의 존재를 함께 확인한다.
- 결과 파일이 삭제되었거나 아직 저장하지 않은 출력 종류를 새로 선택하면 다시 실행할 수 있다.
- 공통 분석 옵션만 바꾼 것을 시간·키워드 변경과 동일하게 취급하지 않는다. 공통 옵션 변경만으로 URL을 자동 재수집하는 요구는 추가하지 않는다.
- 완료 기록은 공통 기본 설정과 분리해 저장 위치의 `.cvc_completed`에 보관하고, 재실행 후에도 사용할 수 있게 한다.
- 이전 결과는 적용 범위·키워드·종료 정책 등을 확인할 수 있을 때만 동일 작업으로 인정한다. 파일명만 같거나 판정 근거가 부족하면 임의로 건너뛰지 않는다.
- TXT 분석 탭의 반복 분석은 허용한다.

## 9. 방송 날짜·시작·종료 시각

- 방송 시작 시각은 VOD 상세 API의 `liveOpenDate`를 사용한다.
- `publishDate`는 VOD 게시 날짜로 구분하고, 방송 시작 시각의 대체값으로 사용하지 않는다.
- API의 시간대 없는 방송 시작 문자열은 현재 확인한 KST 기준으로 표시한다. 시간대 정보가 있는 입력은 KST로 변환한다.
- 방송 종료 표시는 `방송 시작 시각 + 영상 길이`로 계산한다.
- 종료에는 `계산값: 방송 시작 + 영상 길이`처럼 계산 근거를 명시한다. API에서 실제 종료 시각을 별도로 확인한 것처럼 표시하지 않는다.
- 시작 또는 길이가 없거나 유효하지 않으면 계산할 수 없는 정보는 미확인으로 남긴다.
- 기존 파일명 날짜는 게시 날짜 기준을 유지한다. 실제 방송 날짜가 다르다는 이유로 파일명 규칙을 바꾸지 않는다.
- 이 변경은 방송 메타데이터의 표시 요구다. 개별 채팅 실제 시각을 방송 시작+경과 시간으로 무조건 추정하라는 요구로 확대하지 않는다.

## 10. TXT 가독성과 호환성

### 10.1 참고 자료와 원칙

- 사용자가 제공한 `멀럭킹` 폴더의 v1.3 수집 TXT·분석 TXT를 가독성 기준으로 삼는다.
- 서식은 최대한 비슷하게 맞추되, v2.0에서 변경한 구간 정렬·키워드 포함 채팅 비율·종료 경계 등 분석 정책을 v1.3 산식으로 되돌리지 않는다.
- 한글·이모지·특수문자·인용부호·대괄호를 보존한다. 기존 TXT의 여러 줄 채팅도 한 메시지로 읽는다.
- 새 TXT뿐 아니라 기존 v1.3 TXT와 초기 v2.0에서 생성한 JSON 행 기반 TXT도 계속 분석할 수 있게 한다.

### 10.2 수집 TXT

기본적인 채팅 행은 다음 형태를 따른다.

```text
[00:00:09][닉네임] "채팅 내용"
[00:00:09][다른 닉네임] "같은 초의 다음 채팅"
```

- 각 채팅 경과 시간은 `HH:MM:SS`로 표시한다. `.123` 같은 소수 초는 출력하지 않는다.
- 초 미만 값은 반올림하지 않고 버린다. 같은 초에 속한 메시지를 하나로 합치거나 중복 제거하지 않고 채팅 순서를 유지한다.
- 프리미어 옵션을 켜면 시간만 `HH:MM:SS:00`으로 표시한다. 마지막 `00`은 편의용 표기이며 실제 프레임 정보가 아니다.
- 내부 수집·분석에는 원본 정밀도를 유지한다. 초 단위 TXT로 내보낸 데이터에서 사라진 소수 초를 재로딩 시 복원할 수 있다고 주장하지 않는다.
- 방송 정보 헤더와 채팅 본문은 구분한다. 일반 채팅 행을 JSON 객체 덩어리로 노출하지 않는다.
- 제어 문자나 줄바꿈·구분 문자는 읽기와 재분석을 위해 이스케이프할 수 있으나, 재로딩 시 메시지 내용을 보존해야 한다.

### 10.3 분석 TXT

상단부터 다음 순서로 배치한다.

```text
====================================
CHZZK VOD CHAT ANALYZER
====================================

====================================
방송 정보
====================================

채널
예시 채널

제목
예시 방송 제목

====================================
분석 정보
====================================

파일명
YYYY-MM-DD_VOD번호

총 채팅
12,345

====================================
적용 옵션
====================================

분석 구간 단위
1분

====================================
채팅량 TOP10
====================================
```

- 방송 정보만 별도의 `[방송 정보]`·콜론 나열로 문서 맨 위에 붙이지 않는다. 프로그램 제목 아래에서 다른 정보 영역과 같은 구분선·항목명·값·여백 서식을 사용한다.
- 방송 정보에는 채널·제목·VOD ID·URL·방송 날짜·게시 날짜·시작·계산 종료·전체 길이를 정리한다.
- 분석 정보에는 파일명·대상 채팅 수·구간당 평균·키워드·분석 범위·범위 근거·종료 경계를 정리한다.
- 적용 옵션에는 분석 단위·이동평균·TOP 개수·최소 컷·반복 제한·병합 제한·상세 로그·시간 표시를 정리한다.
- 이후 네 종류의 TOP과, 설정한 경우 상세 로그를 출력한다.
- v1.3 예시처럼 순위와 시간을 먼저 보여주고, 그 아래 채팅 수·키워드 수·비율·증가율을 읽기 쉽게 배치한다.
- 병합 내부는 시간순으로 표시하고, 부분 구간과 유효 범위는 요청 범위를 넘지 않도록 표시한다.
- 구분선·빈 줄·숫자 자릿수·증가율 표시를 일관되게 사용한다.

## 11. 실행파일과 사용자 문서

- Windows 사용자는 명령어 입력이나 별도 Python 설치 없이 EXE 더블클릭으로 GUI를 실행할 수 있어야 한다.
- 기존 `chzzk_blue_icon.ico`를 실행파일과 창 아이콘에 사용한다.
- 콘솔 창 없는 GUI 실행파일로 배포한다. 직접 빌드한 결과 위치는 `dist`다.
- README는 개발용 실행·빌드·테스트 명령 나열 대신 프로그램의 생성 목적, 실행파일 실행 방법, 탭별 사용법, 옵션과 결과 파일 확인을 중심으로 작성한다.
- 기존 `버전`·`주의` 영역은 README 재작성 시 임의로 삭제·재작성하지 않는다. 이후 사용자가 직접 수정해 확정한 README를 기준으로 유지한다.
- EXE와 로컬 예시 자료는 소스 저장소와 구분한다. 소스에 실행파일이 항상 포함된다고 안내하지 않는다.
- 실제 Release 게시 여부는 별도 배포 작업으로 확인한다. README에 배포 경로가 있다는 이유만으로 업로드 완료를 의미하지 않는다.
- 캐시·빌드 중간 파일 정리와 Git 커밋·푸시는 작업 관리 요청이며, 프로그램의 자동 정리·자동 Git 업로드 기능으로 추가하지 않는다.

## 13. 검증 범위와 미확인 사항
