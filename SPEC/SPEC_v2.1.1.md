# ChzzkVodChat v2.1.1 Specification

작성일: 2026-11-17 · 최종 수정: 2026-11-18

기준은 [SPEC_v2.1.md](SPEC_v2.1.md)이며 아래 변경사항을 우선한다.

### 저장 위치 정책 최종 수정

설정과 출력 경로는 다음 규칙으로 고정한다.

- 출력 위치와 설정 위치 선택 UI 및 설정 경로 표시는 제거한다.
- 설정·완료 기록·채널별 결과는 항상 현재 EXE가 있는 배포 폴더에 저장한다.
- `CVC_settings.json`은 EXE 옆에서만 읽는다. 예전 `output_dir`, `settings_location.json`, AppData 경로를 참조하지 않는다. 새 설정에는 출력 절대 경로를 저장하지 않는다.
- 배포 폴더를 이동·복사한 경우 이전 폴더의 존재 여부와 무관하게 현재 폴더의 옵션을 복원하고 현재 폴더로 출력한다. 폴더 전체를 함께 이동해야 기존 옵션과 결과도 유지된다.
- 쓰기 권한이 없으면 오류를 안내하고 다른 폴더로 자동 전환하지 않는다.
- 재현·회귀 기준: [TC_v2.1.1_001](../QA/But_report.md/TC_v2.1.1_001.md).

- EXE와 `_internal`을 포함하는 폴더형 ZIP을 사용한다. 실행 라이브러리를 `%TEMP%`에 압축 해제하지 않는다.
- 설정·완료 기록·채널별 결과는 `_internal`과 나란히 보관한다. `_internal` 안에 사용자 데이터를 저장하지 않는다.
- AppData에는 새 파일을 쓰지 않는다. 기존 AppData 데이터와 경로 기록 파일은 참조하거나 자동 삭제하지 않는다.
- 코드나 문서 수정 요청만으로 EXE를 자동 생성하지 않는다. 사용자가 실행 파일 빌드를 명시적으로 요청했을 때만 수행한다.

## 1. 옵션 도움말

- 옵션 입력 박스·체크박스의 툴팁을 제거한다. 화면에 항상 보이는 외부 설명은 유지한다.
- 영상별 시작·종료·키워드 입력 도움말과 파일 경로 툴팁은 유지한다.

## 2. 내부 완료 기록

- `.cvc_completed`는 완료 작업 중복 실행 방지용 내부 기록이며 EXE 옆에 생성한다.
- 해당 배포 폴더의 결과 파일이 있는지 확인해 완료 작업을 구분한다. 기록이 없으면 확인 가능한 기존 결과에서 완료 여부를 판단한다.
- 사용자 결과물과 기존 AppData 기록은 자동 삭제하지 않는다.

## 3. 설정 위치

- `적용`은 현재 EXE 옆 `CVC_settings.json`에 옵션을 저장한다. 저장 실패를 성공으로 표시하지 않는다.
- 경로 선택 옵션과 별도 경로 기록 파일은 제공하지 않는다. 예전 설정의 `output_dir`는 무시한다.
- 폴더 전체를 이동하거나 복사하면 이전 폴더가 남아 있어도 현재 폴더의 설정을 사용한다.

## 4. 방송 정보 축약

수집 TXT와 분석 TXT의 방송 정보는 다음 여섯 항목만 표시한다. 분석 결과의 기존 항목 배치는 유지한다.

```text
[방송 정보]
채널: 멀럭킹
제목: [진수컵] 다키스트던전  끗
VOD URL: https://chzzk.naver.com/video/15944884
방송 시작: 2026-10-30 18:02:05
방송 종료: 2026-10-31 05:10:03
전체 방송 길이: 11:07:58
```

- VOD ID·방송 날짜·VOD 게시 날짜·시간 표시 항목과 KST·계산값 괄호 설명을 제거한다.
- 시각 계산은 기존 KST 규칙을 유지한다. 시작은 `liveOpenDate`, 종료는 시작+길이 계산값이다. 미확인 값은 `미확인`으로 표시한다.
- TXT 재분석 시 VOD ID는 URL에서 복원한다. 기존 TXT도 계속 읽을 수 있어야 한다.

## 5. 수용 기준

- 옵션 박스에는 툴팁이 없고 외부 설명은 보인다.
- 완료 기록은 EXE 옆 `.cvc_completed`에 생성되고 완료 작업 건너뛰기가 유지된다.
- 출력·설정 경로 선택 UI가 없으며 새 설정 파일에 출력 절대 경로를 저장하지 않는다.
- 배포 폴더 전체를 이동·복사한 뒤 이전 폴더의 존재 여부와 관계없이 현재 옵션을 읽고 현재 폴더에 출력한다.
- 수집·분석 방송 정보는 여섯 항목이며 축약 TXT 재분석이 가능하다.
