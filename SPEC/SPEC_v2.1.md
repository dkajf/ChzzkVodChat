# ChzzkVodChat v2.1 Specification

작성일: 2026-11-17

## 1. 목적과 적용 기준

수집 결과의 방송 정보·채팅·후원 표시를 정리하고, 기본 저장 위치와 설정 파일 보관 위치 및 진행률 표시를 개선한다.

- 기준 문서는 [SPEC_v2.0.1.md](SPEC_v2.0.1.md)와 [SPEC_v2.0.md](SPEC_v2.0.md)이다. 충돌하는 항목은 이 문서를 우선한다.
- 별도로 변경하지 않은 수집·분석 기능과 기존 TXT 읽기 호환성, 설정 복구, 안전한 저장 정책은 유지한다.
- 이 문서는 요구사항이며 구현·검증 완료를 의미하지 않는다.

## 2. 수집 결과 표시 및 후원 표시

### 2.1 수집 TXT 형식

수집 결과는 다음 구조를 따른다. 채팅 예시는 출력 형식 설명용이며 실제 API 응답 검증 자료는 아니다.

```text
[방송 정보]

채널: 멀럭킹
제목: 와우 포에버 노움 짱갈래 냉법 -휴방-
VOD ID : 16107843
VOD URL : https://chzzk.naver.com/video/16107843
방송 시작 : 2026-11-10 00:18:30 (KST)
전체 방송 길이: 08:34:07

[채팅 내역]

[07:38:00] [다이노봇] [후원 10,000원] "솔직히 2영기 아니었으면 이미 2영지였다고"
[07:38:01] [우리애긔쓸애긔] "역시 닥던에 멀가주 보이스는 신이야"
[07:38:06] [국빱맨] [후원] "할수있다 나라면!!!(영지 터짐)"
[07:38:09] [때껄룱] "내가 아는 멀럭의 강점은 개같이 꼬여도 거기에서 온몸 비틀기로 살아나가는 능력인데. 이런 단기결전형 리세마라 권장 대회에서는 잘 먹힐지 잘 모르겠음."
[07:38:12] [넵충고] "영기를 많이 뽑는자가 승리한다"
```

- 일반 채팅: `[HH:MM:SS] [닉네임] "채팅 내용"`
- 금액이 공개된 후원: `[HH:MM:SS] [닉네임] [후원 10,000원] "채팅 내용"`
- 금액이 비공개인 후원: `[HH:MM:SS] [닉네임] [후원] "채팅 내용"`
- 후원 표시는 후원 메시지에만 추가한다. 형식 설명에 사용한 소괄호는 출력하지 않는다.
- 후원 금액은 천 단위 쉼표와 `원`을 붙인다. 비공개 금액을 `0원`으로 표시하거나 추정하지 않는다.
- 시간은 VOD 기준 경과 시간이며 기본 형식은 `HH:MM:SS`다. 기존 프리미어 시간 표시 옵션을 켰을 때의 `:00` 추가 정책은 유지한다.
- 일반 채팅과 후원은 기존 수집 순서·시간 정렬 및 중복 방지 정책을 유지한다.
- 새 후원 표기가 있는 TXT도 채팅 분석 탭에서 읽을 수 있어야 한다. 후원 표기와 금액을 메시지 본문이나 키워드 집계에 섞지 않는다.
- 별도 후원 집계·순위·분석 화면은 이번 요청에 포함하지 않는다.

### 2.2 방송 시작 일시

- 다시보기 상세 API `GET /service/v3/videos/{vod_id}` 응답의 `content.liveOpenDate`를 실제 라이브 방송 시작 일시로 사용한다.
- `Last-Modified`에서 영상 길이를 빼는 방식은 사용하지 않는다. `publishDate`는 VOD 게시 날짜로 구분하며 방송 시작 일시를 대신하지 않는다.
- 시간대가 없는 API 날짜는 한국 시간(KST, UTC+09:00)으로 해석한다. 시간대가 있는 값은 KST로 변환한다.
- 날짜를 포함해 `YYYY-MM-DD HH:MM:SS (KST)`로 표시한다. 자정을 넘는 방송도 시작 날짜와 게시 날짜를 구분한다.
- 필드 누락·빈 값·파싱 실패 시 방송 시작을 `미확인`으로 표시하고 채팅 수집은 계속한다. 다른 날짜나 HTTP 헤더로 시작 일시를 추정하지 않는다.
- 방송 종료 일시를 추가로 표시할 경우 `방송 시작 일시 + 전체 방송 길이`로 계산하고 계산값임을 명시한다.
- 이 규칙은 v2.0.1의 API 방송 시작 시각 사용 정책을 유지한다. 초기 v2.1 초안의 `Last-Modified` 계산 제안은 폐기한다.
- 참고: [yt-dlp CHZZK 추출기](https://github.com/yt-dlp/yt-dlp/blob/master/yt_dlp/extractor/chzzk.py).
- 실제 API 확인(2026-11-17): VOD `16107843`의 `liveOpenDate`는 `2026-11-10 00:18:30`, `duration`은 `30847`초(`08:34:07`)였다.

## 3. 기본 저장 폴더와 설정 파일

- 최초 실행의 기본 결과 저장 위치는 실행 파일이 있는 폴더로 한다. 실행 당시의 작업 디렉터리를 기준으로 삼지 않는다.
- 기존 채널별 하위 폴더 구조는 유지한다. 실행 파일 폴더를 결과 저장의 기준 폴더로 사용한다는 의미다.
- 설정 파일은 결과 저장의 기준 폴더에 함께 보관한다. 채널별 하위 폴더마다 설정 파일을 생성하지 않는다.
- 사용자가 결과 저장 위치를 변경해 적용하면 설정 파일의 보관 위치도 해당 기준 폴더에 맞춘다.
- 재실행 시 사용자가 마지막으로 적용한 저장 위치와 설정을 복원할 수 있어야 한다. 변경된 위치를 찾는 방법과 기존 설정 파일 이관 방식은 구현 시 정하며, 사용자가 매번 다시 선택해야 하는 구조는 허용하지 않는다.
- 현재 구현은 `%APPDATA%\ChzzkVodChat\settings_location.json`에 설정 파일 경로만 기록해 재실행 시 참조한다. 실제 옵션 값은 결과 저장 기준 폴더의 `CVC_settings.json`에 보관한다.
- 기존 설정이 있으면 사용자 지정 저장 위치와 옵션을 임의로 초기화하지 않는다.
- 설정 파일명·스키마 및 손상 복구 정책은 기존 기준을 유지한다. 위치 변경 과정에서 기존 설정을 무단으로 덮어쓰거나 유실하지 않는다.
- 실행 파일 폴더 또는 선택한 폴더에 쓰기 권한이 없으면 원인을 안내하고 저장 가능한 위치를 선택할 수 있게 한다. 저장 실패를 성공으로 표시하지 않는다.

## 4. 진행률 표시

- 현재의 반복 이동 방식 대신 **0%부터 100%까지 채워지는 진행률 바**를 제공한다.
- 진행률 바와 함께 숫자 백분율을 표시한다.
- 작업 시작 시 0%로 초기화하고 실제 처리에 따라 증가한다. 정상 완료 후 100%를 표시한다.
- 수집·분석·파일 저장 단계를 포함해 실행한 작업 전체의 진행 상황을 나타낸다. 여러 항목 실행 시 현재 항목과 전체 처리 개수도 확인할 수 있게 한다.
- 진행률 계산 기준은 실제 수집 범위·처리량·단계 완료 상태에 연결한다. 단순 시간 경과만으로 임의의 진행률을 올리지 않는다.
- 전체 처리량을 아직 알 수 없는 정보 조회 단계는 해당 상태를 문구로 안내한다. 계산 근거가 확보되면 수치 진행을 갱신한다.
- 수집 종료만으로 전체 작업을 100%로 표시하지 않는다. 요청한 분석과 결과 저장까지 완료되어야 한다.
- 실패·취소는 완료와 구분하며 100% 성공으로 표시하지 않는다. 다음 실행에서는 진행률을 새로 초기화한다.
- 진행률 갱신 중에도 창 조작과 기존 취소 기능이 응답해야 한다.
