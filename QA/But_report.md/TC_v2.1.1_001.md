# TC_v2.1.1_001 — 배포 폴더 이동 후 이전 경로 참조

작성일: 2026-11-18

## 재현 조건과 절차

1. 기존 배포 폴더 A의 설정에 `output_dir=A`와 변경된 옵션(TOP 17개)을 저장한다.
2. `settings_location.json`에도 A의 설정 경로를 기록한다.
3. 설정을 포함한 폴더 전체를 B로 복사한다.
4. A를 그대로 둔 경우와 A를 제거한 경우 각각 B에서 실행한다.

## 수정 전 결과

- A가 남아 있으면 B 대신 A의 설정 파일을 선택했다.
- A가 없어도 설정 읽기 결과의 출력 위치는 A였다. GUI의 추가 보정에 의존하는 구조였다.
- 자동 재현 테스트에서 두 조건 모두 실패하는 것을 확인했다.

## 기대 결과와 수정

- 항상 현재 EXE 옆 B의 설정만 읽고 TOP 17개를 유지한다.
- 설정 저장·수집 TXT·분석 TXT·완료 기록은 모두 B 안에 생성한다.
- 이전 경로 기록과 설정의 `output_dir`는 무시한다. 새 설정 파일에는 출력 경로를 기록하지 않는다.
- 옵션에서 저장 위치 변경 UI와 설정 경로 표시를 제거한다.

## 검증

- `tests/test_portable.py`에서 A 존재·삭제 두 조건의 설정 복원과 수집·분석·완료 기록 저장을 검증한다.
- GUI 검사는 출력 위치 옵션과 폴더 선택 기능이 없는지 확인한다.
- 수정 후 Windows Tk GUI를 포함한 전체 45개 테스트가 통과했다.
- 실제 EXE 이동 검사는 아직 수행하지 않았다. 이 작업에서 빌드하지 않는다.
