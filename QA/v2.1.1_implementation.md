# v2.1.1 구현·검증

작성일: 2026-11-17

## 후속 저장 정책 수정

- 최신 검증: 경로 고정 수정 후 Windows Tk GUI 포함 전체 45개 테스트 통과. 이전 폴더가 존재하는 복사와 이전 폴더가 없는 이동 조건에서 옵션 복원·결과 저장을 확인했다.

- 2026-11-18 추가 수정: 배포 폴더 복사 시 이전 위치의 설정을 참조하는 문제를 재현해 `TC_v2.1.1_001`과 자동 테스트를 추가했다. 출력·설정 경로 선택과 경로 표시 UI를 제거하고 EXE 폴더로 고정했다. 기존 절대 출력 경로와 경로 기록 파일은 무시하며 새 설정에는 출력 경로를 쓰지 않는다. 아래의 사용자 지정 경로 유지 정책보다 이 규칙을 우선한다. 빌드는 수행하지 않았다.

- 2026-11-18 최종 선택: `_internal`을 포함한 폴더형 ZIP으로 다시 변경했다. 출력물과 설정은 기본적으로 EXE가 있는 배포 폴더에 `_internal`과 나란히 생성한다. 기존 사용자 지정 저장 위치는 유지한다. 빌드 설정과 문서만 수정했으며 EXE·ZIP은 새로 생성하지 않았다. 아래 단일 EXE 선택은 이전 기록이다.

- 최종 사용자 선택: `%TEMP%` 임시 압축 해제를 사용하는 단일 EXE 방식으로 빌드 설정을 변경했다. 아래 폴더형 배포 내용은 이전 작업 기록이다. 이 정책 변경에서는 EXE를 빌드하지 않았으며 기존 산출물은 갱신하지 않았다. 이후에도 명시적인 빌드 요청이 있을 때만 EXE를 생성한다.

- 사용자 요청으로 AppData 신규 쓰기를 제거했다. 설정과 완료 기록은 결과 폴더, 경로 기록은 EXE 옆으로 변경했다. 이전 AppData 자료는 읽기만 하고 자동 삭제하지 않는다.
- 단일 EXE 임시 압축 해제도 피하도록 폴더형 배포로 변경했다. 기존 단일 EXE 대신 폴더형 ZIP을 사용한다.
- 수정 후 전체 44개 테스트 통과. AppData 신규 생성 없이 설정 경로를 EXE 옆에 저장하는 검사 포함.
- 아래 목록의 AppData 저장·단일 EXE 설명은 이전 구현 기록이며 위 정책으로 대체됐다.

- 옵션 박스 툴팁 제거, 외부 도움말 유지.
- 완료 기록을 결과 폴더에서 AppData로 변경. 기존 기록은 작업별 확인 시 유효성을 검사한 후 이관하고 빈 폴더만 제거한다.
- 저장 위치 변경 시 현재 설정 전체 복사 및 다음 실행 복원 유지. EXE 옆 설정의 이전 출력 폴더가 사라진 경우 이동한 설정 폴더로 복원한다. 설정 파일만 임의의 위치로 이동한 경우 자동 검색은 지원하지 않는다.
- 방송 정보는 채널·제목·URL·시작·종료·길이 여섯 항목으로 축약. TXT 읽기는 기존 형식과 새 형식을 지원한다.
- 핵심·실제 TXT 샘플·신규 동작·Windows Tk GUI 총 44개 테스트 통과.
- 축약 헤더에서 제거한 게시 날짜는 임의 이름의 TXT 재분석 시 복원할 수 없다. 기존 날짜_VOD 파일명인 경우 파일명에서 복원한다.
- PyInstaller 단일 GUI EXE 빌드 대상: `dist/ChzzkVodChat_v2.1.1.exe`. EXE 직접 실행 검증은 별도 수행하지 않았다.
