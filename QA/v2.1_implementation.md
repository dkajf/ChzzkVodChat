# v2.1 구현·검증 기록

작성일: 2026-11-17

- 방송 시작: 기존 `content.liveOpenDate` 파싱을 유지하고 SPEC의 Last-Modified 계산 규칙을 교체했다. VOD `16107843` 실응답에서 시작 `2026-11-10 00:18:30`, 길이 `30847`초를 확인했다.
- 수집 TXT: `[채팅 내역]`과 공백을 둔 채팅 표기, 공개 금액·금액 없는 후원 표기를 추가했다. 후원 여부·금액을 본문과 별도로 보관하며 기존 TXT 형식도 읽는다. 빈 본문의 후원도 보존한다.
- 설정: 실행 파일 폴더를 기본값으로 사용한다. 설정은 결과 기준 폴더에 저장하고 AppData 경로 파일로 재탐색한다. 기존 AppData 설정은 원본을 보존하여 이관한다.
- 진행률: 반복 애니메이션을 제거했다. 수집은 VOD 경과 범위에 따라 0~80%, 수집 저장 80%, 분석 시작 85%, 분석 저장 시작 95%, 전체 항목 정상 완료 100%를 사용한다. 분석·저장 중에는 단계 완료 전까지 해당 값에 머문다. 복수 작업은 항목별 진행률의 평균이다.

## 검증 결과

- 핵심·샘플·v2.1 테스트 29개 통과.
- Windows Tk GUI 테스트 13개 통과. 진행률의 수집 완료 후 저장 대기, 정상 완료, 실패, 재실행 초기화를 포함한다.
- 일반 제한 환경에서는 Tcl 초기화가 실패했다. 권한을 허용한 환경에서 GUI 테스트를 실행해 통과했다.
- 기존 실제 TXT 샘플 4개(30,568~42,773개 채팅)의 재분석 검사를 통과했다.
- 후원 파싱·TXT 왕복·금액의 키워드 집계 제외는 테스트 데이터로 검증했다. 실제 VOD의 공개·비공개 후원 응답 대조는 아직 수행하지 않았다. 현재 후원 판정은 `messageTypeCode=10` 또는 `extras.donationType=CHAT/VIDEO`, 금액은 `extras.payAmount`의 양의 정수 값을 사용한다. 비공개 응답의 별도 숨김 필드 유무도 실제 데이터에서 추가 확인이 필요하다.
- EXE 빌드 완료: `dist/ChzzkVodChat_v2.1.exe`. 창 제목과 패키지 버전 표기를 v2.1로 변경했다. GUI 라이브러리가 누락된 최초 제한 환경 빌드는 사용하지 않고, 권한이 허용된 환경에서 Tkinter를 포함해 다시 빌드했다. EXE 직접 실행 검증은 수행하지 않았다.
