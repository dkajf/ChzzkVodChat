# ChzzkVodChat v2.1.1 테스트 케이스

## 기능 로드맵

```text
프로그램 실행
├─ 배포 폴더의 CVC_settings.json 로드 또는 초기 설정 복구
├─ 수집·분석
│  ├─ VOD URL 등록 → 방송 정보 조회 → 영상별 분석 조건 입력
│  ├─ 수집 TXT / 분석 TXT 선택 → 실행 → 완료 기록 확인
│  └─ 전체 VOD 채팅 수집 → 선택한 TXT 저장
├─ 채팅 분석
│  ├─ 수집 TXT 등록 → 채팅·방송 정보 읽기 → 파일별 분석 조건 입력
│  └─ 분석 TXT 저장 → 목록에서 조건을 바꿔 재분석 가능
├─ 옵션
│  └─ 공통 설정 편집 → 적용 / 취소 / 기본값 복원
└─ 공통 작업 흐름
   ├─ 하단에서 진행률과 항목별 오류 확인
   ├─ 저장 폴더 열기 → 채널별 결과 확인
   └─ 작업 중 창 닫기 → 취소·종료 여부 확인
```

## 테스트 목적

- 자동 테스트로 URL의 TXT 처리, 분석 집계, 결과 저장 등 핵심 기능의 실행 및 회귀를 확인한다.
- 수동 테스트로 배포 EXE의 실행과 실제 VOD 수집을 확인하고, 화면 배치, 입력 흐름, 오류 안내 등 UI/UX 개선점을 찾는다.

## 테스트 준비

- 배포 ZIP 전체를 테스트 폴더에 풀고 EXE를 실행한다. 이때 독립된 복사본에서 실행한다.
- 채팅이 있는 공개 VOD, 조회 불가 VOD, 채팅 시각과 내용이 알려진 경계값용 TXT를 준비한다.
- 아래 표는 기대 결과를 정의한다. 실행 시 사용한 빌드, 입력, 실제 결과와 통과 여부를 기록한다.

## URL 수집·분석

| ID | 절차 | 기대 결과 |
| --- | --- | --- |
| URL-01 | 공개 VOD를 Enter와 [+]로 각각 등록한다. 같은 VOD에 쿼리나 끝 슬래시를 붙여 다시 등록하고, 서로 다른 URL로 10개와 11개 등록을 시험한다. | 방송 정보가 표시된다. 동일 VOD 번호는 중복 등록되지 않는다. 최대 10개를 등록할 수 있다. |
| URL-02 | 라이브 URL, 다른 사이트, 조회 불가 VOD를 넣는다. 조회 중인 항목을 [-]로 제거한다. | 형식 또는 조회 오류가 표시된다. 늦게 도착한 응답이 삭제된 항목을 복구하거나 다른 행을 바꾸지 않는다. |
| URL-03 | 여러 VOD를 등록하고 방송 정보와 영상별 입력을 확인한다. 옵션의 기본 키워드를 변경한 뒤 새 VOD를 등록한다. | 채널명·제목·방송 날짜·길이가 표시된다. 새 행은 시작 시간 00:00:00, 영상 끝 시간, 적용된 기본 키워드를 표시한다. 행마다 입력값을 독립적으로 변경할 수 있다. |
| URL-04 | 수집 TXT만, 분석 TXT만, 둘 다, 둘 다 해제를 각각 시험한다. 수집 TXT만 저장할 때는 분석 입력에 잘못된 값을 남겨 둔다. | 선택한 종류만 저장된다. 분석 TXT만 선택해도 채팅을 수집한다. 수집 전용은 분석 입력을 비활성화하고 전체 VOD를 수집한다. 둘 다 해제하면 실행할 수 없다. |
| URL-05 | 채팅이 없는 구간과 같은 시각의 서로 다른 채팅을 포함한 VOD를 수집한다. 모의 응답에서 페이지 간 동일 채팅도 반복한다. | 처리 가능한 페이지를 끝까지 수집한다. 시간순으로 저장하고, 페이지 중복은 제거하며, 같은 시각의 서로 다른 채팅은 유지한다. |
| URL-06 | 동일한 VOD·분석 조건·출력으로 실행한 뒤 앱을 재실행하고 반복한다. 이후 시간이나 키워드 변경, 결과 파일 삭제, 빠진 출력 종류 추가를 각각 시험한다. | 필요한 결과가 모두 남아 있는 동일 작업은 건너뛴다. 변경된 분석 조건이나 필요한 결과가 없는 작업은 실행할 수 있다. 성공한 URL 작업은 배포 폴더의 .cvc_completed에 기록된다. |
| URL-07 | 완료 기록이 없는 테스트 폴더에 일치하는 기존 결과를 배치한다. 이후 보고서의 키워드나 종료 경계가 다른 경우도 시험한다. | 호환되는 결과에서 완료 기록을 복원한다. 분석 조건을 확인할 수 없거나 일치하지 않으면 작업을 실행할 수 있다. |

| TXT-04 | 영상 길이가 있는 파일과 없는 파일의 종료 시간을 비워 분석한다. | 길이가 있으면 영상 끝을 사용한다. 길이가 없으면 마지막 채팅이 속한 집계 구간의 끝을 사용하고 채팅 데이터 기준 범위로 표기한다. |

## 분석 입력·집계

| ID | 절차 | 기대 결과 |
| --- | --- | --- |
| AN-01 | HH:MM:SS, HHMMSS, MMSS를 입력한다. 시작·종료·키워드 공란과 키워드 10자·11자, 60초, 시작≥종료, 영상 길이 초과를 각각 시험한다. | 세 시간 형식을 인식한다. 시작 공란은 0초, 종료 공란은 자동 범위, 키워드 공란은 ㅋ를 적용한다. 범위 오류와 11자 키워드는 안내한다. |
| AN-02 | 상세 로그를 켜고 5분 단위로 00:02:00~00:07:00을 분석한다. 00:01:59, 00:02:00, 00:05:00, 00:06:59, 00:07:00에 채팅을 둔다. | 시작 경계는 포함하고 지정 종료 경계는 제외한다. 00:05:00 채팅은 두 번째 구간에 들어간다. 상세 로그의 부분 구간은 00:02:00~00:05:00과 00:05:00~00:07:00으로 표시되고 총 3건이 집계된다. |
| AN-03 | 알려진 영상 길이와 같은 시각에 채팅을 둔다. 자동 종료와 동일 시각을 직접 입력한 종료로 각각 분석한다. | 자동 종료는 영상 끝점 채팅을 마지막 구간에 포함한다. 직접 지정한 종료는 끝점 채팅을 제외한다. 분석 정보에 각 종료 경계가 표시된다. |
| AN-04 | 1분 단위, 이전 2분 기준으로 구간별 채팅 수가 0·2·6인 자료를 분석한다. 최소 채팅 수 0과 3을 비교한다. | 처음 두 구간의 증가율은 N/A다. 세 번째 구간의 이전 평균은 1, 증가율은 +500%다. 최소값 0이면 구간당 전체 평균 8/3을 적용하고 직접 지정하면 3을 적용한다. |
| AN-05 | 한 구간에 ㅋㅋㅋㅋ와 일반 채팅을 1건씩 넣고 키워드 ㅋ로 분석한다. 반복 제한을 2와 0으로 비교한다. | 키워드 개수는 각각 2와 4다. 키워드 포함 채팅 비율은 두 경우 모두 50%다. |
| AN-06 | 동점, 인접 구간, 떨어진 구간이 있는 자료에서 TOP 개수와 최대 병합 구간 수 0·1·2를 비교한다. | 네 TOP의 병합 전 순위는 각 지표 내림차순이다. 동점은 이른 구간이 우선이며 비율 동점은 키워드 개수를 먼저 비교한다. 병합은 인접 구간에만 적용되고 0은 무제한, 1은 단일 구간, 2는 최대 두 구간이다. 병합 내부는 시간순이며 각 목록은 설정한 TOP 개수 이하다. |
| AN-07 | 채팅이 없는 구간 및 키워드 일치가 없는 파일을 분석한다. 상세 로그를 켜고 끈 결과를 비교한다. | 후보가 없는 TOP은 대상 없음으로 표시된다. 상세 로그를 켜면 빈 구간을 포함한 분석 범위의 구간 통계가 시간순으로 나오고, 끄면 상세 로그 절이 생략된다. |
| AN-08 | 작업을 시작한 뒤 옵션을 수정·적용하고 다음 작업을 실행한다. | 실행 중 작업은 시작 시점의 옵션을 사용하며, 다음 작업부터 변경된 옵션이 적용된다. |

## 저장·진행·오류

| ID | 절차 | 기대 결과 |
| --- | --- | --- |
| OUT-01 | 게시 날짜와 방송 날짜가 다른 VOD의 수집·분석 TXT를 저장한다. 같은 이름으로 재실행할 수 있게 분석 조건을 바꾼다. | EXE 옆 채널 폴더에 게시 날짜 기준 YYYY-MM-DD_VOD번호.txt와 YYYY-MM-DD_VOD번호_analysis.txt가 생성된다. 이름이 겹치면 번호가 붙은 새 파일이 저장되고 기존 내용이 유지된다. |
| OUT-02 | 한글·이모지·따옴표와 일반·후원 채팅이 섞인 VOD를 수집하고 생성 TXT를 다시 읽는다. | UTF-8로 읽을 수 있고 경과 시각·닉네임·본문을 확인할 수 있다. 후원은 금액이 있으면 [후원 10,000원] 형태로, 금액이 없으면 [후원]으로 표시된다. 생성한 TXT로 재분석할 수 있다. |
| OUT-03 | 실제 시각 표시와 프리미어 옵션을 켜고 끈다. 방송 시작 정보가 있는 VOD와 없는 자료를 비교한다. | 프리미어 옵션을 켜면 경과 시간에 :00이 붙는다. 실제 시각 표시를 켜면 근거가 있는 채팅은 실제 일시가, 근거가 없으면 미확인이 표시된다. 방송 시작은 liveOpenDate를 사용하며 방송 종료는 시작과 영상 길이로 계산한 값으로 표시된다. |
| OUT-04 | 여러 항목을 실행하며 실행 버튼을 연속 클릭한다. 수집·분석·저장 단계와 저장 폴더 열기를 확인한다. | 작업이 중복 시작되지 않고 창이 응답한다. 진행률은 수집·분석·저장을 반영하며 전체가 정상 완료되면 100%가 표시된다. 저장 폴더 열기는 현재 배포 폴더를 연다. |
| OUT-05 | 배치 내 한 항목에 지속적인 API 오류 또는 저장 실패를 유도하고 다른 항목은 정상 입력으로 둔다. 일시적인 API 오류도 별도로 재현한다. | 일시 오류는 제한된 횟수 안에서 재시도한다. 실패 항목에 오류가 표시되고 다른 항목을 계속 처리한다. 실패한 쓰기의 임시 파일은 정리된다. |
| OUT-06 | 여러 항목 중 하나를 저장한 후 작업 중에 창을 닫는다. 확인창에서 계속 실행과 취소·종료를 각각 시험한다. | 종료를 거절하면 진행이 계속된다. 승인하면 작업을 취소하고 창이 닫힌다. 이미 저장한 결과는 남고, 저장 중이던 파일은 불완전한 최종 TXT로 남지 않는다. |
