# CHZZK VOD CHAT

CHZZK VOD CHAT은 치지직 다시보기의 채팅을 수집하고, 반응이 많은 시간대를 분석하는 Windows 프로그램입니다.

긴 방송을 처음부터 다시 살펴보지 않아도 채팅량이 늘어난 구간이나 특정 키워드가 많이 등장한 구간을 찾아, 방송 복기와 하이라이트·영상 편집에 참고할 수 있도록 만들었습니다. 채팅 원문과 분석 결과는 TXT로 저장하며, 저장한 채팅은 다른 범위나 키워드로 다시 분석할 수 있습니다.

## 실행 방법

release 를 통해서 최신 버전 파일을 받을 수 있습니다

직접 빌드한 실행 파일은 프로젝트의 `dist` 폴더에 있습니다. GitHub 소스 코드만 받은 경우에는 실행 파일이 포함되어 있지 않습니다.

상단에는 **수집·분석 / 채팅 분석 / 옵션** 탭이 있습니다. 처음 사용하는 경우 옵션에서 저장 위치를 확인한 뒤 진행하세요.

## 수집·분석

치지직 VOD URL로 채팅을 수집하고, 필요한 경우 분석 결과까지 함께 저장합니다.

1. `URL 입력 후 Enter로 등록` 영역에 다시보기 URL을 입력합니다.
2. Enter 또는 `[+]`를 누르면 영상이 등록되고 방송 정보를 불러옵니다.
3. 채널명·제목·방송 날짜·영상 길이를 확인합니다.
4. 영상별 시작 시간·종료 시간·키워드를 설정합니다.
5. 화면 아래에서 저장할 TXT를 선택하고 `실행`을 누릅니다.

URL은 최대 10개까지 등록할 수 있고, 여러 URL을 줄바꿈으로 붙여넣을 수도 있습니다. 같은 VOD는 중복 등록되지 않습니다. 등록한 항목은 `[-]`로 제거할 수 있으며, 정보 조회에 실패하면 `재조회`를 눌러 다시 시도합니다. 정보 조회 중이거나 실패한 항목은 실행 대상에서 제외됩니다.

### 저장할 결과 선택

| 선택 | 처리 내용 |
|---|---|
| 채팅 수집 TXT 저장 | 채팅 원문만 저장 |
| 채팅 분석 TXT 저장 | 채팅을 수집한 뒤 분석 결과만 저장 |
| 두 항목 모두 선택 | 채팅 원문과 분석 결과를 모두 저장 |

둘 다 선택하지 않으면 실행할 수 없습니다. 수집 TXT만 저장할 때는 영상별 분석 입력칸이 비활성화됩니다.

**수집은 전체 VOD를 대상으로 하며**, 시작·종료 시간은 **분석할 범위**를 정하는 값입니다. 분석 결과만 선택해도 채팅 수집은 필요합니다.

### 시간과 키워드 입력

| 항목 | 입력 방법 |
|---|---|
| 시작 시간 | 기본 `00:00:00`. 빈칸도 처음부터 분석 |
| 종료 시간 | URL 정보 조회 후 영상 끝 시간이 자동 입력됨. 직접 수정하거나 비워둘 수 있음 |
| 키워드 | 새 항목은 옵션의 기본 키워드 사용. 입력칸을 비우면 `ㅋ` 적용. 최대 10자 |

시간은 `HH:MM:SS`, 숫자 6자리 `HHMMSS`, 숫자 4자리 `MMSS`로 입력할 수 있습니다. 예를 들어 `01:23:45`와 `012345`는 같고, `2222`는 `00:22:22`입니다.

직접 지정하는 종료 시간은 시작 시간보다 커야 하며 영상 길이를 넘을 수 없습니다. 지정한 종료 시각의 채팅은 분석에서 제외됩니다. 자동으로 채워진 영상 끝 시간은 마지막 채팅을 포함하는 자동 종료로 동작하고, 직접 수정한 종료 값은 재조회해도 유지됩니다.

같은 시간·키워드로 완료한 작업은 결과 파일이 남아 있으면 건너뜁니다. 시간이나 키워드를 변경하거나, 결과 파일을 삭제하거나, 아직 저장하지 않은 출력 종류를 선택하면 다시 실행할 수 있습니다.

## 채팅 분석

이미 저장한 수집 TXT를 불러와 **재수집 없이** 분석하는 탭입니다. 기존 버전의 수집 TXT와 현재 버전의 수집 TXT를 모두 지원합니다.

1. `TXT 파일 추가`를 눌러 분석할 채팅 TXT를 선택합니다. 여러 파일을 함께 선택할 수 있습니다.
2. 파일마다 시작 시간·종료 시간·키워드를 입력합니다.
3. `분석 TXT 저장`을 누릅니다.

등록한 파일은 `[-]`로 제거할 수 있습니다. 파일별 입력값은 서로 독립적이며, 수집·분석 탭의 출력 체크박스는 이 탭에 영향을 주지 않습니다. 원본 TXT는 수정하지 않습니다.

종료 시간을 비워두면 영상 길이가 있는 TXT는 영상 끝까지, 길이가 없는 TXT는 채팅 데이터 끝까지 분석합니다. 방송 정보가 없는 구버전 파일의 제목이나 실제 방송 시작 시각 등은 미확인으로 표시될 수 있습니다.

같은 파일을 다른 설정으로 반복 분석할 수 있습니다. 등록한 원본 파일의 내용이 바뀌었다면 목록에서 제거한 뒤 다시 추가하세요.

## 옵션

영상별 시간·키워드를 제외한 공통 설정을 변경합니다. 각 옵션 아래에 설명이 있으며, 아래쪽 항목은 마우스 휠로 스크롤해 확인할 수 있습니다.

| 옵션 | 적용 내용 |
|---|---|
| 저장 위치 | 채널별 결과 폴더를 만들 위치 |
| 새 영상 기본 키워드 | 새로 등록하는 URL·TXT의 초기 키워드 |
| 분석 단위 | 1~10분 단위 집계. 기본 1분 |
| TOP 개수 | 각 TOP 목록의 최대 순위 수 |
| 이동평균 이전 N분 | 현재 구간을 제외한 이전 구간의 평균과 비교. 분석 단위의 배수로 지정 |
| 최소 채팅 수 | TOP 후보의 최소 채팅량. `0`은 분석 범위의 구간당 평균 |
| 키워드 반복 제한 | 한 채팅에서 셀 키워드의 최대 반복 횟수. `0`은 무제한 |
| 최대 병합 구간 수 | 연속된 TOP 구간을 묶는 최대 개수. `0`은 무제한, `1`은 병합 안 함 |
| 상세 로그 저장 | 분석 범위의 모든 구간 통계를 시간순으로 추가 |
| 프리미어 입력용 시간 표시 | 경과 시간 뒤에 `:00` 추가. 실제 프레임 계산은 하지 않음 |
| 수집 TXT 실제 시각 표시 | 근거가 있는 채팅의 실제 날짜·시각 표시. 근거가 없으면 미확인 |

`적용`을 누르면 설정을 저장하고 이후 작업에 사용합니다. `취소`는 적용 전 편집을 되돌리며, `기본값 복원`은 확인 후 기본 설정을 적용·저장합니다. 실행 중 설정을 바꾸더라도 이미 시작한 작업에는 영향을 주지 않습니다.

## 분석 결과 읽기

분석 TXT에는 방송 정보, 분석 범위와 채팅 수, 적용 옵션, 네 종류의 TOP, 선택한 경우 상세 로그가 기록됩니다.

- **채팅량 TOP**: 채팅이 많이 올라온 구간
- **이동평균 대비 증가율 TOP**: 이전 평균보다 채팅량이 크게 늘어난 구간
- **키워드 개수 TOP**: 지정한 키워드의 등장 횟수가 많은 구간
- **키워드 포함 채팅 비율 TOP**: 전체 채팅 중 키워드를 포함한 메시지의 비율이 높은 구간

분석 구간은 VOD 시작을 기준으로 정렬합니다. 예를 들어 5분 단위라면 `00~05분`, `05~10분`으로 나뉩니다. 범위를 중간부터 지정하면 그 범위 안의 채팅만 집계하고, 일부만 포함된 구간은 부분 구간으로 표시합니다.

연속된 TOP 구간은 병합 설정에 따라 묶어서 보여줍니다. 이전 평균이 없거나 0이면 증가율은 `N/A`로 표시하고 증가율 TOP에서 제외합니다. 키워드 반복 횟수와 포함 채팅 비율은 다른 값이므로, 한 메시지에 키워드가 여러 번 등장해도 비율 계산에서는 한 메시지로 셉니다.

채팅 경과 시간은 `HH:MM:SS`로 기록합니다. 프리미어 옵션을 켜면 `HH:MM:SS:00`으로 표시합니다. 방송 시작은 확인 가능한 API 정보를 사용하고, 종료는 시작 시각에 영상 길이를 더한 **계산값**으로 구분합니다. 방송 날짜와 VOD 게시 날짜는 다를 수 있습니다.

## 저장 파일과 작업 종료

기본 저장 위치는 사용자 폴더 아래 `Documents\ChzzkVodChat`이며, 옵션에서 변경할 수 있습니다. 각 실행 버튼 옆의 `저장 폴더 열기`로 결과를 확인하세요.

```text
저장 폴더/
└── 채널명/
    ├── YYYY-MM-DD_VOD번호.txt
    └── YYYY-MM-DD_VOD번호_analysis.txt
```

파일명의 날짜는 VOD 게시 날짜를 기준으로 합니다. 같은 이름의 파일이 있으면 기존 파일을 덮어쓰지 않고 새 이름으로 저장합니다.

작업 진행 상태와 오류는 창 아래에 표시됩니다. 여러 항목 중 하나가 실패해도 다른 항목은 계속 처리합니다. 작업 중 창을 닫으면 취소하고 종료할지 선택할 수 있으며, 이미 저장을 마친 결과 파일은 유지됩니다.

설정은 `%APPDATA%\ChzzkVodChat\CVC_settings.json`에 저장됩니다. 저장 폴더 안의 `.cvc_completed`는 완료 작업을 구분하는 기록이므로, 같은 작업의 중복 실행을 막으려면 함께 보관하세요.
